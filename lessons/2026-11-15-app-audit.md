# App-wide audit: every route, plus a code read of the hot paths

## What

Every route was swept on the dev server in two passes. The first was over HTTP: status,
title, h1 and meta description. The second ran in the browser: unnamed controls, images
with no alt, horizontal overflow, small tap targets and duplicate ids. That covered 28
routes. A code read covered the player, detail pages, search, home and the header.

Fixed:

- **Detail info rows.** A movie with no director rendered a "Director" link that searched
  for `undefined`. A running show had a "Last Air Date" label with no value, and titles
  with no country had an empty "Original Country". One `filledInfoRows` guard in the
  shared layout now covers both formatters.
- **Person search links** were built without encoding, so a name containing `&` cut the
  query short. `personSearchHref` is shared by the info rows and the credits.
- **Credits.** "Crew" was gated on the unfiltered crew list, so it showed over an empty
  grid when nobody was a Director, Writer or Producer. "Cast" showed with no cast.
- **Empty overview** now reads "No synopsis yet." instead of a blank paragraph.
- **Search.**
  - The chained ternary for result thumbnails became `ResultThumb`.
  - Thumbnails now have `alt=""`, because the title already sits beside them.
  - The "remove recent search" X is visible on touch and is a real tap target.
- **Mobile menu.** The menu button's focus ring is restored. The drawer is capped at
  85vw, so a 320px phone keeps a strip of backdrop to tap closed.
- **Storage.** `rescue-banner` and `use-match-room` touched `localStorage` with no guard,
  which is the same Safari crash fixed earlier today. They now use `lib/safe-storage.ts`,
  which gained `storageRemove`.
- **/account** had no h1 when signed out.
- **/start** poster buttons had no accessible name until their image loaded.

## Mistakes

- **I ran `seo:verify` against `https://www.reely.space`** and got 10 false failures: the
  script prefixes `www.` itself. Pass nothing, or the apex domain.
- **TaskStop on `wrangler dev` left workerd, esbuild and wrangler running.** The next
  `pnpm dev` then died in Turbopack with `0xc0000142`, because its PostCSS worker could
  not start, and every route returned 500. It looked like a code regression for three
  restarts. Before suspecting the app, kill the orphaned processes by command line.
- **The first browser audit ran synchronously across 28 iframes** and hit the 45s CDP
  limit. Start it in the background, keep results on `window`, and poll.

## What worked

- A cheap HTTP pass first (status, h1, description). It found the /account gap in seconds.
- An in-page audit run in same-origin iframes covers every route in one tool call.

## Rules

- Grep for raw `localStorage.` after any storage fix. One fixed call site leaves its
  siblings broken.
- Decide whether a section heading shows from the list it actually renders, not from the
  unfiltered list.

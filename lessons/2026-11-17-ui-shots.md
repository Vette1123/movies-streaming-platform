# pnpm shots: a visual-QA pass on live

## What

`pnpm shots` (scripts/ui-shots.mjs) screenshots 7 routes on https://www.reely.space at
phone (390, or `--phone-width 320`) and desktop (1440): first screen, full page and
viewport-height slices. It exits 1 naming any element wider than the viewport. Built on
the existing scripts/lib/headless-chrome.mjs; ported from the downloader repo's script.

## Mistakes

- The brief listed `/search?q=dune`; Reely has no such route (search is a palette), so it
  was dropped instead of screenshotting a 404.
- The first full run takes ~3 min (6 s settle per view, 28 views); a foreground call got
  backgrounded by the harness. Run it in the background.
- One `pnpm test` run showed 4 failures under load that did not reproduce on rerun.
- No visual defects came out of the first pass; no wrong turn beyond the above.

## What worked

- Live serves headless Chrome without a Cloudflare challenge; the script still refuses to
  grade one.
- Slices scrolled to (not clipped) so content-visibility sections are painted.
- 390, 320 and 1440 all report no horizontal overflow on every route.

## Rules

- Reuse the existing CDP helper before porting another.
- A QA script that finds nothing is only believed after the overflow gate is seen to read
  a real scrollWidth; the verdict line prints the number it measured.

# Daily search-engine run, 2026-11-21

## What

- `pnpm seo:daily` + `.github/workflows/seo-daily.yml` (4×/day), ported from portfolio-v1's daily
  jobs: resubmit the sitemap index and every child to Search Console and Bing, check Google has
  read each sitemap within 7 days with no errors, and check Bing's quota, crawl issues, crawl
  counters and index size. A failed run mails the owner.
- First live run: 4 sitemaps submitted and read today; Bing flagged ConnectionTimeout 27 on
  2026-11-20 against a week median of 1.

## Mistakes

- Portfolio's Bing rule ("any 5xx, timeout or robots block above 0 is a fault") would have failed
  every Reely run: Code5xx sits near 40 every day and both sites carry a robots block. Calibrated
  on 10 days of live stats first; the rule is now a jump above the prior week's median.

## What worked

- Reading both sites' real numbers before choosing thresholds.

## Rules

- A health check copied between sites gets its thresholds from the target site's own history.
- Portfolio's D1-backed URL Inspection report was not ported; the sitemap read covers the gap that
  actually bit (tv.xml unread). Port it only if pages drop out while sitemap reads stay clean.
